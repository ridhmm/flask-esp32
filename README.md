> **Final Year Project / Thesis**
> Backend server for automatic license plate recognition using YOLOv5 and OCR, integrated with an IoT Smart Gate system via MQTT.

---
## 🛠️ Prerequisites
Before running the program, ensure your computer meets the following requirements:

1.  **Python**: Version **3.8 - 3.10**.
    * *⚠️ Note:* Avoid Python 3.11+ due to frequent compatibility issues with Machine Learning libraries.
2.  **MQTT Broker**: (e.g., Mosquitto).
    * This program uses **Port 1884**. Ensure the broker is running on this port (not the default 1883), or adjust the configuration in `server.py`.

---
## 📦 Installation
### 1. Clone & Enter Directory
Open your terminal and run the following commands to download the project:
```bash
git clone https://github.com/ridhmm/flask-esp32.git
cd flask-esp32
```

### 2. Create Virtual Environment (Recommended)
Ensure Python is installed, then run:

```bash
# Create Environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (Mac/Linux)
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```
Note: If you encounter errors with torch or fast-plate-ocr, it is recommended to install them manually according to your OS and Hardware (CPU/GPU) specifications.

---
## 🚀 Usage
1. Start the MQTT Broker (Mosquitto) first. Run this command in your terminal:
```bash
mosquitto -c /opt/homebrew/Cellar/mosquitto/2.0.22_2/etc/mosquitto/mosquitto.conf -v
```
>(Note: Adjust the config path if necessary)

2. Run the Main Script:
```bash
python server.py
```
3. Wait for Initialization: 
> Wait until the following message appears: Running on http://x.x.x.x:5001

---
## 🧪 Testing
1. Open your browser and access: http://localhost:5001
2. You will see the monitoring dashboard.
3. Use the upload form on the dashboard to manually test the image detection logic.

## 📂 Struktur Folder (Wajib)

To ensure the system runs without File Not Found or TemplateNotFound errors, the project folder structure must look like this:

```text
📁 folder_proyek_ta/
├── 📄 server.py              # Main Flask server file (Backend)
├── 📄 best.pt                # Trained YOLOv5 model (REQUIRED)
├── 📄 requirements.txt       # List of dependencies
├── 📁 templates/             # HTML template folder (Required for Flask)
│   └── 📄 index.html         # Web Dashboard View File
├── 📁 static/                # Assets folder (Auto-generated by system)
│   ├── 📁 uploads            # Stores full images from ESP32
│   └── 📁 plates             # Stores cropped license plate images
└── 📁 yolov5/                # (Optional) Clone ultralytics repo if 'local' load fails
```

## ❓ Troubleshooting
TemplateNotFound:         Ensure the templates folder exists and contains index.html.
MQTT Connection Refused:  Check if Mosquitto is running. Ensure the port in server.py matches the broker (1884).
YOLO Error / Load Failed: Change the model loading code in server.py to use source='github'.
